# 🌐 Vyshnav Reddy Pinreddy – Personal Portfolio Website

This is my **personal portfolio website** — a responsive, interactive, and elegant single-page web application designed to showcase who I am, what I've built, and where I'm headed.

Whether you're a recruiter, collaborator, or fellow developer, feel free to scroll through and explore!

---

## 🔥 Features

- ⚡ **Responsive Layout**: Optimized across devices with media queries for seamless UX.
- 🌙 **Dark Mode Toggle**: One-click dark/light mode switch with persistent styling.
- 🔽 **Smart Navbar Behavior**: Navbar hides on scroll down and reappears on scroll up, enhancing focus and immersion.
- 🖼️ **Project Carousel**: Scroll through featured projects using arrow buttons.
- 📚 **Dynamic Resume Timeline**: Year-wise timeline with clickable buttons that update the education panel accordingly.
- 💬 **Animated About Section**: Swipe between multiple cards giving an insight into who I am.
- ✨ **Smooth Scroll Navigation**: All internal links use smooth scrolling for a polished effect.
- 📱 **Fully Responsive Design**: Layout adjusts beautifully across desktops, tablets, and phones.
